### Changed
- The grading tool is now the **hoe** (any hoe, right-click) instead of the shovel, so shovels keep their vanilla path-making. Grading cancels the vanilla action on both client and server only when the move would be accepted, so grass is still tilled by a hoe as usual. A plain dirt block with open air above (what a hoe would till) is graded only while sneaking.
